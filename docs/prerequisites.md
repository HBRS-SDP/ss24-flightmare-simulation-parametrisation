## Prerequisites
We have followed the instructions provided on [Flightmare installation guide](https://flightmare.readthedocs.io/en/latest/getting_started/quick_start.html#quick-start):

### Installing Flightmare with ROS 1:

 - ### Requirments
   - **cmake v3.28.4**
   - **gcc v9.40**
   - **openmpi v4.03**
   - **opencv v4.5.5**
   - **Zeromq v4.3.2**
   - **profibus v3.20.3**

 A detailed instruction to install all the above mentioned packages are given [here.](/docs/setup_instructions_with_ros.md).

### Installing Flightmare with python:

 - ### Requirments
   - **cmake v3.28.4**
   - **gcc v9.40**
   - **openmpi v4.03**
   - **opencv v4.5.5**
   - **Zeromq v4.3.2**
   - **tensorflow v1.15**

 A detailed instruction to install all the above mentioned packages are given [here.](/docs/setup_instructions_with_python.md).
